# Qué es la facturación electrónica y qué necesitás para activarla

Este artículo aplica solo a comercios en Paraguay. La facturación electrónica es el sistema con el que tus ventas se declaran automáticamente ante el fisco a través de SIFEN (el Sistema Integrado de Facturación Electrónica Nacional, de la SET — Subsecretaría de Estado de Tributación). En vez de una factura de papel con talonario impreso, cada venta genera un Documento Electrónico (DE) firmado digitalmente, que queda validado ante el Estado.

## Qué es cada término

- **SET**: el organismo del Estado paraguayo que administra los impuestos.
- **SIFEN**: el sistema al que se envía cada comprobante electrónico para que quede registrado.
- **DE (Documento Electrónico)**: el archivo firmado que es, legalmente, tu factura. Es el que tiene valor fiscal.
- **KuDE**: la representación en papel o PDF de ese DE — lo que la gente reconoce como "la factura". El KuDE es solo la versión legible del DE; el documento que vale ante la SET es el archivo firmado.
- **RUC**: el Registro Único de Contribuyente, tu identificación como empresa ante la SET.
- **Número de timbrado**: la autorización que la SET le da a tu comercio (y a cada caja) para emitir comprobantes. Sin un timbrado vigente, no se puede facturar.

## Qué necesita tu comercio antes de activarla

1. **Estar habilitado por la SET como facturador electrónico**, con tu RUC y tu razón social correctamente registrados.
2. **Tener un certificado de firma digital** vigente, que es lo que firma cada documento electrónico en tu nombre.
3. **Tener un código de seguridad (CSC)** asignado por la SET, necesario para generar el código QR de tus comprobantes.
4. **Tener un timbrado vigente para cada caja que vaya a facturar.** En Punto, cada caja es un punto de expedición propio: el timbrado, el establecimiento y el punto de expedición se cargan por caja, no una sola vez para todo el comercio.

## Cómo se activa en Punto

1. Entrá a Configuración › Facturación electrónica.
2. Completá los datos del emisor: RUC, razón social, actividad económica y establecimientos de tu comercio.
3. Cargá el certificado de firma y el código de seguridad (CSC).
4. Cargá el timbrado de cada caja que vaya a emitir comprobantes electrónicos. Esto se hace desde Sucursales › (tu sucursal) › Cajas › editar la caja: número de timbrado, establecimiento y punto de expedición, vigencia y numeración de facturas.
5. Si usás distintos medios de pago (efectivo, tarjeta, transferencia, etc.), revisá el mapeo de medios de pago para que cada uno se declare con el código correcto.

Mientras el emisor está en proceso de habilitación, algunas partes de la configuración (como el mapeo de medios de pago) quedan bloqueadas hasta que el alta se complete.

## Qué pasa una vez activada

Con la cuenta habilitada y cada caja con su timbrado cargado, las ventas de esas cajas emiten su Documento Electrónico automáticamente al cobrarse — no hace falta ninguna acción extra del cajero. Cómo se emite, se consulta y se entrega el comprobante al cliente está explicado en [Emitir, consultar y entregar el comprobante](70-02-emitir-consultar-y-entregar-el-comprobante.md).

## Preguntas frecuentes

**¿Todas mis cajas tienen que facturar electrónicamente?**
Cada caja tiene su propio timbrado. Una caja sin timbrado cargado no puede emitir comprobantes electrónicos.

**¿Qué pasa si mi certificado de firma vence?**
Sin un certificado vigente no se pueden firmar (y por lo tanto no se pueden emitir) documentos electrónicos nuevos. Renovalo antes del vencimiento para no interrumpir la facturación.

**¿El ticket que imprime la caja es lo mismo que la factura electrónica?**
No necesariamente son el mismo papel. El documento con valor fiscal es el DE firmado; su representación (el KuDE) se pone a disposición para el cliente y se puede imprimir. Ver el detalle en el siguiente artículo.
