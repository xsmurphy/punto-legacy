# Cómo configurar sucursales y cajas

Si tu negocio tiene uno o más locales, cada uno se representa en Punto como una sucursal. Dentro de cada sucursal configurás sus cajas — los puntos donde efectivamente se cobra — y sus depósitos, donde se contabiliza el stock. Esta pantalla es la base antes de empezar a vender: sin al menos una sucursal y una caja activa, no se puede operar.

## Cómo se organiza tu negocio en Punto

- Tu negocio puede tener una o varias **sucursales** (locales).
- Cada sucursal tiene sus **depósitos**, donde se lleva la cuenta del stock disponible.
- Cada sucursal tiene una o varias **cajas**, que son los puntos donde se cobra. Cada caja tiene su propia numeración de comprobantes.

## Crear o editar una sucursal

1. Buscá "Sucursales" en el buscador del panel y entrá a esa pantalla.
2. Para crear una nueva, usá la opción de agregar sucursal; para editar una existente, hacé clic en ella.
3. Completá los datos:
   - **Perfil**: nombre de la sucursal.
   - **Datos fiscales**: la información que tu país exige para identificar ese local ante el fisco.
   - **Contacto**: teléfono y dirección de correo del local.
   - **Ubicación**: dirección física.

## Configurar las cajas de una sucursal

Dentro de una sucursal, entrá a la pestaña "Cajas".

1. Hacé clic en agregar caja y ponele un nombre (por ejemplo, "Caja 1" o "Mostrador").
2. Marcá si la caja está activa — una caja inactiva no puede operar.
3. Si querés que el cajero no vea los totales de dinero durante el turno (para reforzar el control en el arqueo de cierre), activá el control de caja a ciegas.
4. Si tu país usa documentos fiscales con numeración propia por caja (como una autorización de facturación), cargá ahí los datos que te dio el organismo correspondiente: el número de autorización, el establecimiento y punto de emisión, la vigencia, y desde qué número arranca la numeración de facturas. Cada caja lleva su propia numeración — dos cajas no pueden compartir exactamente la misma identidad fiscal, porque eso duplicaría comprobantes.
5. Guardá los cambios.

Una vez creada, la caja queda disponible para que un dispositivo (una tablet, una computadora) la tome y empiece a vender.

## Si un dispositivo se pierde con una caja tomada

Cuando un dispositivo toma una caja para vender, la caja queda "tomada" por ese dispositivo hasta que se libera. Si el dispositivo se rompe, se pierde, o el empleado se fue sin cerrar la caja correctamente, podés liberar la caja manualmente desde la pestaña Cajas, para que otro dispositivo pueda tomarla.

## Preguntas frecuentes

**¿Puedo tener más de una caja activa al mismo tiempo en la misma sucursal?**
Sí, no hay límite. Cada una factura de forma independiente.

**¿Puedo mover una caja de una sucursal a otra?**
Una caja pertenece a la sucursal donde se creó. Si necesitás mover la operación, se crea una caja nueva en la sucursal de destino.

**¿Qué pasa si no cargo los datos de numeración fiscal de una caja?**
Esa caja no va a poder emitir el documento fiscal correspondiente hasta que se complete esa configuración.
